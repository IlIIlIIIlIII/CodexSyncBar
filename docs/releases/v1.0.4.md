# Codex SyncBar 1.0.4

잠자기 해제 뒤 주간 사용량이 갱신되지 않고 마지막 성공값이 현재값처럼 남아 있던 문제를 수정하고, 공개 앱을 Apple 공증 릴리즈로 전환했습니다.

## 변경 사항

- Mac 잠자기 해제 시 사용량을 즉시 새로고침합니다.
- 앱이 활성화되거나 메뉴를 열었을 때 마지막 갱신이 오래되었으면 다시 조회합니다.
- 다른 갱신이 진행 중일 때 들어온 요청은 버리지 않고 한 번 이어서 처리합니다.
- 갱신 실패 시 이전 퍼센트를 현재값처럼 메뉴 막대에 표시하지 않고 경고 상태로 표시합니다.
- 10분 이상 갱신되지 않은 메뉴 막대 수치는 시간 경고와 함께 숨깁니다.
- 이전 스냅샷이 남아 있어도 메뉴 안에서 마지막 갱신 실패 사유를 표시합니다.
- 공개 ZIP을 Developer ID로 서명하고 Apple 공증 및 티켓 첨부 후 배포합니다.

## 검증

- 새로고침 시점, stale 경계, 실패한 이전 스냅샷 표시를 회귀 테스트로 검증합니다.
- 서명·공증·티켓 첨부·Gatekeeper 평가가 모두 성공한 앱만 릴리즈합니다.
- 기존 계정 전환, 인증, 사용량 및 토큰 집계 테스트를 함께 실행합니다.

## 설치

1. `Codex-SyncBar-1.0.4-macOS-universal.zip`을 내려받아 압축을 풉니다.
2. `Codex SyncBar.app`을 `/Applications`로 옮깁니다.
3. Finder에서 앱을 엽니다.

macOS 13 이상, `/Applications`의 Google Chrome과 공식 Codex CLI가 필요합니다. 이 ZIP은 Apple Silicon과 Intel Mac을 모두 포함하며 Developer ID 서명과 Apple 공증을 완료한 빌드입니다.
