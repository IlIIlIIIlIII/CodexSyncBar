# Codex SyncBar 1.0.2

최근 30일 토큰 사용량에서 포크·재개 세션의 상속 이력이 중복 집계되던 문제를 수정한 패치 릴리즈입니다.

## 변경 사항

- `session_meta`의 세션 ID와 부모 세션 ID를 사용해 부모–자식 계보를 구성합니다.
- 포크 세션이 재생하는 부모의 초기 토큰 이력만 제외하고, 자식 세션의 신규 사용량과 독립 세션의 동일한 토큰 값은 정상 집계합니다.
- 누적 카운터 증가와 리셋, `last_token_usage` fallback, 모델 및 service tier별 집계를 유지합니다.
- 증분 캐시는 변경되지 않은 파일을 다시 더하지 않고, append된 신규 이벤트만 한 번 반영합니다.
- 사용량 캐시 schema를 5로 올려 기존 과다 집계 캐시를 자동으로 재구축합니다.
- Node 집계 경로와 jq fallback이 같은 계보 기반 의미로 계산되도록 맞췄습니다.

## 검증

- 부모·중첩 포크, 독립 세션의 동일 토큰 값, 누적 카운터 리셋, 모델 및 service tier 변경, 30일 경계와 캐시 증분 동작을 회귀 테스트로 검증했습니다.
- 실제 로컬 세션 로그에서 비포크 세션의 합계는 유지하면서 포크 세션의 상속 이력만 제거되는 것을 확인했습니다.

## 설치

1. `Codex-SyncBar-1.0.2-macOS-universal.zip`을 내려받아 압축을 풉니다.
2. `Codex SyncBar.app`을 `/Applications`로 옮깁니다.
3. 처음 한 번은 Finder에서 앱을 Control-클릭하고 **열기**를 선택합니다.

macOS 13 이상, `/Applications`의 Google Chrome과 공식 Codex CLI가 필요합니다. 이 ZIP은 Apple Silicon과 Intel Mac을 모두 포함한 유니버설 바이너리이며 ad-hoc 서명되어 있습니다.
