# Codex SyncBar 1.0.3

1.0.2의 포크 세션 중복 제거가 원격 장치에는 배포되지 않아 모든 기기 합계가 계속 과대 집계되던 문제를 수정한 패치 릴리즈입니다.

## 변경 사항

- `gpt-switch` helper 버전을 2.1.3으로 올려 연결된 원격 장치에도 schema 5 집계기를 설치합니다.
- 원격 helper의 script 버전이 같더라도 사용량 summary schema가 현재 버전과 다르면 helper를 다시 설치하고 집계합니다.
- 재설치 후에도 schema가 맞지 않는 장치의 구 집계값은 전체 합계에 포함하지 않습니다.

## 검증

- 로컬·원격 사용량 집계기의 schema 5 일치와 helper 설치 경로를 회귀 테스트로 검증합니다.
- 포크 계보 기반 중복 제거, 증분 캐시, jq fallback을 포함한 기존 사용량 회귀 테스트를 함께 실행합니다.

## 설치

1. `Codex-SyncBar-1.0.3-macOS-universal.zip`을 내려받아 압축을 풉니다.
2. `Codex SyncBar.app`을 `/Applications`로 옮깁니다.
3. 앱을 다시 실행하면 로컬 helper가 갱신되고, 다음 사용량 수집 때 연결된 원격 helper와 캐시도 갱신됩니다.

macOS 13 이상, `/Applications`의 Google Chrome과 공식 Codex CLI가 필요합니다. 이 ZIP은 Apple Silicon과 Intel Mac을 모두 포함한 유니버설 바이너리이며 ad-hoc 서명되어 있습니다.
