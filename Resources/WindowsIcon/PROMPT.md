# Codex SyncBar Windows icon

Generated with the built-in `image_gen` tool on 2026-09-19 (no CLI fallback).
Master: `SyncBarIcon.png`. Transparent alpha is retained. `Scripts/Windows/prepare-icon.py` resizes and encodes the same artwork for Windows; it does not redraw it.

## Final prompt

Use case: logo-brand
Asset type: Windows app and system tray icon for Codex SyncBar, an account-switching and usage-monitoring utility.
Primary request: Create one polished, original icon, readable at 16–32 pixels: two bold interlocking curved arrows forming a compact S-shaped synchronization mark, with generous negative space. Use a luminous cyan-to-blue mark on a deep navy rounded-square tile, matching a dark Fluent Windows interface. Restrained soft depth, crisp edges, centered symmetrical visual weight; the symbol should fill most of the tile with consistent safe padding.
Composition: one square 1024x1024 icon, tile centered and almost filling canvas, genuinely transparent outside its rounded corners.
Constraints: no text, letters, numbers, border frame, tiny detail, mockup, watermark, multiple variants, or OpenAI knot logo. Keep strong contrast and a simple silhouette.
